# Security Policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Instead, use GitHub's private reporting: on the repository, go to **Security → Report a vulnerability**. If that isn't available, email the maintainer, Daniel Kwadwo Takyi, at **danielkwadwotakyi@gmail.com**.

Please include what you found, steps to reproduce, and its likely impact. You'll get an acknowledgement within a few days, and credit in the fix's release notes if you'd like it.

## Scope

In scope: the API (authentication, authorisation, data access between students), the web app (XSS, open redirects), and the OAuth flow. Out of scope: denial of service through excessive traffic, and issues in third-party services.
